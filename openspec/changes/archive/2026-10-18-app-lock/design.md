# Design

## PIN 怎么存

```
salt       = 16 字节随机数（base64）
digest     = SHA-256 迭代 10000 次(salt || pin)      // 每轮把上一轮结果与 salt 再喂回去
存储键     = app_state: lock_enabled / lock_pin_salt / lock_pin_digest / lock_pin_length
```

- **不加依赖自己写散列**不划算：手写 SHA-256 是"自己造加密"，风险高于收益；`crypto` 是 Dart 官方纯 Dart 实现，没有平台代码。
- 迭代 1 万次让暴力枚举变慢；4 位 PIN 本身空间只有 1 万，所以真正的防线是**错误限速 + 迭代成本**，不是散列强度（这一点在设计里写清楚，避免"看起来安全"的错觉）。
- 校验用常量时间比较，避免理论上的计时侧信道。

## 状态机

```
main()
  └─ LockGate（读 app_state）
        ├─ 未开启 → ShellPage
        └─ 已开启 → LockScreen →（PIN 正确）→ ShellPage
                       ↑
        AppLifecycleState.paused 记录时间；resumed 时超过 60s → 回到 LockScreen
```

- `LockGate` 是 `StatefulWidget + WidgetsBindingObserver`，**不依赖路由**：锁屏替换整棵树，避免"解锁后还能按返回键回到锁屏"这种漏洞。
- 冷启动判定：`LockGate.initState` 里读一次 `isEnabled()`，读库期间显示空白（和明细页首帧同样的处理），不闪内容。

## 锁定页

```
┌────────────────────────┐
│     金豆（豆子图标）      │
│  输入 PIN 解锁             │
│      ● ● ● ○ ○ ○        │
│   （错误时红字提示）         │
│   1    2    3           │
│   4    5    6           │
│   7    8    9           │
│   清除  0   ⌫            │
└────────────────────────┘
```

- 键盘复用记账面板的视觉（白键压在砂色底座上、56 高、圆角 12）。
- 错误提示在圆点下方一行，抖动用 `TweenAnimationBuilder` 做 120ms 位移，不引入额外依赖。
- 限速：第 5 次失败后 `_lockUntil = now + 30s`，期间键盘 `enabled: false` 并显示倒计时。

## 设置页

设置 →「应用锁」→ `AppLockPage`：

- 关闭状态：「开启应用锁」→ 输入 PIN → 再次输入确认 → 保存并开启。
- 开启状态：「修改 PIN」（先验证旧 PIN）与「关闭应用锁」（先验证旧 PIN）。
- 冲突提示：两次输入不一致、长度不对、旧 PIN 错误，都在页面内就地提示。

## 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 锁屏是否走路由 | 替换整棵树（LockGate） | 路由可被返回键绕过；整树替换最简单可靠 |
| 后台多久重新上锁 | 60 秒 | 切出去回个消息不该被打断；离开一会儿才需要重新验证 |
| 散列 | `crypto` 的 SHA-256 + 盐 + 1 万次迭代 | 官方纯 Dart，不引入平台代码；比自造散列安全 |
| 生物识别 | 本轮不做 | 需要 `local_auth` + Android `FlutterFragmentActivity`，平台配置与真机验证单独一轮 |
| 忘记 PIN | 不提供找回 | 本地无账号、无云备份；提示"重装会丢数据"，这是本地优先的代价 |
| 是否需要加密数据库 | 不需要 | 应用锁是"防止别人随手打开"，不是"防止拿到文件的人"；数据库加密是另一个量级（SQLCipher） |

## 风险

| 风险 | 应对 |
|---|---|
| 4 位 PIN 空间小 | 迭代散列 + 错误限速；文档写明威胁模型边界 |
| 忘记 PIN 等于永久锁死 | 设置时提示"忘记后只能重装"；不提供绕过路径 |
| 生命周期回调在测试里难模拟 | `LockGate` 暴露可注入的 `now()` 与超时配置；用例直接调 `didChangeAppLifecycleState` |
| 冷启动读库失败 | 读不到锁配置时按"未开启"放行（不能因为存储异常把用户锁在门外） |
