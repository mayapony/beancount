# Proposal

## Why

选中图片记账已经能用了，但图片只有「加」没有「减」：传错一张、糊了、重复了，只能把整笔账删掉重记。
M7 里「编辑已有交易的图片」缺的就是这个——详情页要能补图、能删图，删掉的图还要真的从磁盘回收。

## What Changes

- **详情页加图**：图片区出现「添加图片」入口（相册/相机），选完立刻落盘挂到这笔记账上。
- **详情页删图**：每张缩略图右上角一个 ✕，确认后删除附件记录；文件在没有其它引用时才真正删掉（沿用既有引用计数）。
- **失败不脏**：写盘失败或交易已不存在时给一句可读提示，不留下半条附件记录。
- **导出/备份不受影响**：图片仍走同一条附件链路，备份 zip 里依旧是文件名引用。
- 非目标：给图片加备注/排序拖动、图片裁剪或滤镜、识别（M7 的另一半）、多选批量删除。

## Capabilities

### New Capabilities

- `attachment-editing`: 交易详情页的图片增删（含确认、引用计数回收与失败提示）

### Modified Capabilities

（无：附件存储、引用计数与备份语义不变，本次只补两个操作入口。）

## Impact

- `lib/pages/transaction_detail_page.dart`：图片区加「添加」与每图删除；选图注入 `ImagePickFn`
- `lib/data/repositories/attachment_repository.dart`：如需按文件名删除则补一个 `removeByName`
- `lib/pages/shell.dart` / 明细页：把选图实现传给详情页
- 测试：仓储按名删除与引用计数、详情页增删交互、备份仍包含图片、设备端回归
