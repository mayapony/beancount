# 金豆 Bean Count · 设计语言（基线）

> 依据 UI UX Pro Max 设计智能库（[uupm.cc](https://uupm.cc) / [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)）
> 中「Personal Finance Tracker」「Soft UI Evolution」等条目 + 「金豆」品牌方向推导。
> 本文件是视觉与交互的单一真相，M10 前定稿。

## 1. 设计理念

**金豆 = 圆豆子 / 小种子，肚子里存金币，「种豆得钱」。**

情绪关键词：**温暖 · 圆润 · 轻盈 · 可信 · 治愈**。

一句话设计语言：*像一颗刚发芽的金豆——圆、暖、有光，装得下钱。*

## 2. 风格基调

**Soft UI Evolution（柔和演变风格）+ 加大圆角。**

- 柔和多层阴影（比扁平更有层次，比纯拟物更克制、对比更好）
- 圆角 12–20px，呼应「豆子」的圆润
- 大量留白，信息密度低（个人记账，不是数据大屏）

> 数据依据：`styles.csv`「Soft UI Evolution」= 现代企业/健康/财务友好、对比达标；
> 「Claymorphism」虽最圆胖但库中标注「不适合金融」，故不采用；
> 「Minimalism」偏冷，与温暖方向冲突。

### 3.2 语义色（记账专用，关键约定）

| 语义 | 颜色 | 说明 |
|---|---|---|
| 收入 | 绿 `#15803D` | 配合 `+` 号与图标，**不靠颜色单独区分** |
| 支出 | 默认文字色（`text`） | 配合 `-` 号；**红只留给警示**，避免整屏红字制造焦虑 |
| 转账 | 中性 `#78716C` | 中灰，双向箭头 |

> 可访问性：颜色只做强化，符号（+/−）与图标才是主区分（参考库中「Inclusive Design」条目）。
> 情绪规则：红 = 警示（超预算 / 负余额 / 逾期），不是日常支出的默认色——「温暖治愈」的品牌不能被红字淹没。

## 4. 字体

- **中文字体**：跟随系统 —— Android `MiSans / HarmonyOS Sans`，iOS `PingFang SC`；不额外打包字体（省体积）。
- **数字/金额**：等宽数字 `tabular figures`（列对齐）+ **千分位分隔** `1,234.56`（长金额阅读速度差 3 倍，硬需求）。
- **字阶**：

| 用途 | 字号/字重 |
|---|---|
| 余额 / 净资产 | 34–40 / SemiBold |
| 页面标题 | 24 / SemiBold |
| 区块标题 | 17 / SemiBold |
| 正文 | 15 / Regular |
| 金额（列表） | 16 / Medium（等宽） |
| 辅助 / 时间戳 | 12–13 / Regular |

## 6. 图标

- 风格：**圆润线性 + 圆角端点**（2px 描边），与圆润基调一致。
- 方案：Material Symbols Rounded（Flutter 内置，可变字重）。
- **列表行**：分类图标 = **实心分类色圆 + 白色字形**（iOS 设置页 / 健康 App 的语言）；**面板网格**：砂色圆 + 暖灰图标，选中才是金色实心圆。

## 7. 图表规范（洞察 tab，fl_chart）

| 图表 | 用途 | 形式 |
|---|---|---|
| 分类占比 | 支出/收入构成 | **环形图**（donut），中心放总额 |
| 收支趋势 | 月度趋势 | 折线 + 渐变面积，金=支出主线 |
| 净资产 | 资产 tab | 面积图，绿=增长 |
| 分类排行 | Top 分类 | 横向条形 + 图标 |

- 图例/数据标签随主题；工具提示轻量（150ms）。
- **洞察页图表 ≤3 张**（环形 + 趋势 + 排行封顶，不堆第 4 张）；月/年切换器放大、置于最显眼位置。
- 数据依据：`products.csv`「Personal Finance Tracker」= 分类 donut + 月度趋势线。

## 8. 动效（Micro-interactions）

- 记账成功：豆子**软弹跳**（soft bounce）+ 触感反馈（haptic）
- 页面切换：淡入/滑动 200–250ms
- 余额数字：滚动过渡
- **动效预算：全 App ≤3 种**（保存弹跳 / 切换淡入 / 数字滚动），其余一律不要
- 所有动效尊重系统 `reduced-motion`

## 9. 核心组件

1. **记账金豆（灵魂）**：**中心停靠**（底部导航挖 notch）—— `明细 / 洞察 / [金豆] / 资产 / 设置`，金色圆豆永远停在拇指热区。按下**直接进入金额键盘**（1 次点击），不再有中间菜单。
   **记账节奏 ≤3 秒**：金额优先、键盘就位；分类/类型/时间继承上次值，无需重选。
   **面板结构**（`lib/widgets/quick_entry_sheet.dart`）：
   标题「记一笔」+ 支出/收入分段 → 分类 **4 列 × 3 行**（灰阶图标 + 金色实心圆选中）→ 账户 / 时间胶囊 → **金额卡**（金额 + 备注行：图片 / 相机 / 标签）→ 键盘（砂色底座 + 白键，**贴底不随内容滚动**）。
   三条不可破的规则：**① 同屏只有一个强调色**（选中分类 + 完成）；**② 白键必须压在 `sand` 底座上**；**③ 金额是唯一的大字号**。
2. **底部导航**：4 Tab（明细/洞察/资产/设置）+ **中心凹槽**，金豆"嵌"在凹槽里（品牌资产，保留）。
   实现：金豆由 `BeanBottomNav` 自己的 Stack 绘制（不是 `Scaffold.floatingActionButton`），否则底栏会盖住它的投影；凹槽用固定圆心的 `_BeanNotchedShape`；顶边发丝线在凹槽处断开 78px；**底栏只占自身高度（68 + 安全区），金豆用 `Clip.none` 画到容器外**，否则 Scaffold 会把探出的 31px 算进底部安全区，内容区与底栏之间空出一条死带（2026-10-17 修）。选中态 = 金色图标 + 金色文字（不再加胶囊底）。
3. **金额展示**：支出默认文字色 `-`、收入绿 `+`、转账中性；**千分位** + 等宽数字右对齐。
4. **交易列表项**：左侧分类 tinted 圆底图标，中部备注+分类+账户，右侧金额+时间。
5. **空状态（品牌叙事位）**：空页画**一颗种子** + 「种下第一笔」文案；记完变绿芽，连续记账天数让它长大 —— 「种豆得钱」的具象化。
6. **截图记账（自动能力）**：用户截屏后**自动**弹出识别结果 → 确认即入账。不设常驻入口，仅在设置中提供开关与识别范围。
7. **备注与标签（面板内）**：备注用弹窗编辑（避免系统键盘顶掉数字键盘），最多 40 字；标签为预设多选，选中后以 `#标签` 前缀显示在备注行。两者都随这笔账一起提交。**「再记」后的确认文案落在备注行**（绿色 ✓），不用 SnackBar —— SnackBar 会被 modal 面板挡住。
8. **账户与时间（面板内二级面板）**：两个胶囊点开都是同款底部小面板（暖灰拖拽条 + 40 圆关闭键）。
   - 账户：一行一个（分类圆底图标 + 名称 + 类型 + 余额），选中打金色钩；余额两位小数、负号在 `¥` 前，欠款才用警示红。
   - 时间：快捷 `今天 / 昨天 / 前天`（改日期、保留时分）+ 日期时间滚轮（中文、24 小时制）+ 整条实心 `完成`；滚轮文字取主题 `titleLarge` 并强制跟随亮暗。
   - 分类 / 类型 / 账户都会继承上一次记账的选择。

## 10. 可访问性

- 正文对比 ≥ 4.5:1，大字 ≥ 3:1
- 收支区分**不依赖颜色**（+/- 号 + 图标）
- 触控目标 ≥ 44×44px；金额键盘键高 ≥ 56px 防误触
- 焦点可见 + reduced-motion 支持
